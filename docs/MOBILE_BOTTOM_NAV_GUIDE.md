# Mobile Bottom Navigation Guide

## Objetivo

La barra inferior estilo Sanvat entrega accesos rapidos sin reemplazar el menu lateral. El drawer conserva todas las paginas; la barra inferior muestra solo cinco accesos.

## Defaults

Modo personal:

- Inicio
- Mis finanzas
- Movimientos
- Simulador
- Ajustes

Modo cartera:

- Inicio
- Creditos
- Clientes
- Simulador
- Ajustes

## Personalizacion

En `Configuracion > Accesos rapidos` el usuario puede:

- subir o bajar accesos;
- ocultar accesos;
- restaurar defaults.

La preferencia se guarda en `localStorage`:

- `credios-bottom-nav-order`
- `credios-bottom-nav-hidden`

No requiere migracion ni datos sensibles.
