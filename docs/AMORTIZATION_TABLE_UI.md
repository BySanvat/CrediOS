# Amortization Table UI

## Cambios

- Tablas con `border-spacing-y` para respirar.
- Celdas con padding mayor.
- Numeros con `tabular-nums`.
- Filas alternadas:
  - superficie base;
  - `accent-soft` muy suave.
- Bordes redondeados por fila.
- Scroll horizontal solo dentro del contenedor si el viewport es pequeno.

## Rutas revisadas

- `/simulador`
- `/creditos/[slug]`

## Criterio visual

La tabla puede seguir siendo tecnica, pero no debe sentirse como una hoja de calculo cruda ni generar scroll horizontal global.
