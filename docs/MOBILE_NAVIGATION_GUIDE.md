# Mobile Navigation Guide

## Drawer

El menu movil usa una superficie oscura translucida con blur controlado:

- fondo base negro;
- opacidad visible, no transparente total;
- scroll interno;
- cierre al tocar fuera;
- cierre por swipe hacia la izquierda.

## Barra inferior

La barra inferior es para accesos frecuentes. El drawer mantiene todas las rutas.

## Inicio privado

La experiencia privada prioriza `/finanzas` como inicio de la app.
